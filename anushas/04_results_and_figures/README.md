# Results and Figures

This folder contains the output artifacts generated by the `anushas` data cleaning, exploratory analysis, and modeling workflows.

## Folder structure

- `correlations/`
  - `test1/` — placental correlation tables and associated variable summaries.
  - `test2/` — Fitbit correlation tables and associated variable summaries.
  - `test3/` — demographic correlation diagnostics and visualizations.
  - `test4/` — Fitbit differential distribution results.
- `data_analysis/`
  - `clinical/` — clinical summary outputs.
  - `fitbit/` — Fitbit analysis logs, plots, and diagnostic tables.
  - `placental/` — placental histopathology summary outputs.
- `models/` — model fitting outputs from `03_model_development/run_fitbit_glm_interactions.py`.

## Correlation outputs

### `correlations/test1/`

- `full_correlation_table_placental.txt`
- `filtered_correlation_table_placental.txt`
- `positively_associated_vars_placental.txt`
- `negatively_associated_vars_placental.txt`

These files summarize Spearman correlations and FDR-filtered associations for placental histopathology features.

### `correlations/test2/`

- `full_correlation_table_fitbit.txt`
- `filtered_correlation_table_fitbit.txt`
- `positively_associated_vars_fitbit.txt`
- `negatively_associated_vars_fitbit.txt`

These files summarize Spearman correlations and FDR-filtered associations for Fitbit-derived features.

### `correlations/test3/`

- `demographics_correlation_matrix.csv`
- `demographics_vif.txt`
- `demographics_correlation_heatmap.png`

These outputs capture demographic variable correlations, collinearity diagnostics, and the resulting heatmap visualization.

### `correlations/test4/`

- `fitbit_differential_distribution.csv`
- `fitbit_differential_distribution_significant.csv`

These files contain results from differential distribution analysis on Fitbit features.

## Regeneration notes

Run the relevant scripts from the `anushas` project root to regenerate outputs:

```bash
python 01_data_cleaning/preprocess_fitbit.py
python 01_data_cleaning/preprocess_placental.py
python 02_exploratory_analysis/analyze_clinical.py
python 02_exploratory_analysis/analyze_fitbit.py
python 02_exploratory_analysis/correlation.py
python 03_model_development/run_fitbit_glm_interactions.py
```

- `data_analysis/` contains analysis summaries and diagnostic tables.
- `correlations/` contains detailed correlation and association result tables.
- `models/` contains GLM model logs and aggregated results.
